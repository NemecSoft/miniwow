# Crisp Quest Free Theme

A free carved-wood fantasy RPG UI Theme with 52 PNG pieces: buttons, panels, window, inventory slots, health and mana bars, dialogue box, check box, slider, icons.

Free sampler of Crisp Quest: https://anipixels.itch.io/crisp-quest
Demo scene: `res://addons/crisp_quest_free/demo/quest_free_demo.tscn`
Documentation: https://github.com/Anipixels/crisp-quest-free-theme
